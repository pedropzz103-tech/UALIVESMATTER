# UA LIVES MATTER

Android MVP focused on civilian safety information in Ukraine.

## v0.1
- OpenStreetMap + Leaflet map
- Community alert creation/confirmation UI
- General chat prototype
- Survival/offline guidance section
- SOS quick action
- Transport/shelter layer placeholders
- Native Android WebView shell
- GitHub Actions APK build

> Civilian-safety only. The project must not expose real-time troop positions, military movements, or other operational military data.

## Build
GitHub Actions builds a debug APK on every push to `main`.
